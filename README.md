# AI 智能硬件 · 跨场景调研

[查看线上展站](https://zhang-yvxuan.github.io/Design-Thinking/)

设计思维课程成果，分四页浏览：

| 页面 | 展示内容 | 数据加载 |
|---|---|---|
| 首页 | 主视觉、精选案例、设计观察 | 只读取首页数据 |
| 案例与观点 | 80 张可检索案例卡、5 页案例原卡、48 张观点卡 | 案例和观点独立请求，默认每批 9 项 |
| 场景与用户 | 4 类、44 个末级场景，分析文字和原分类图所列案例 | 每次只加载一个场景的分析文本；点击后才载入高清图 |
| 资料库 | 116 个资料获取入口、5 份成员数据包、60 条文献索引 | 仅切到文献时读取论文索引 |

## 本地预览

在站点目录运行 `python -m http.server 8137 --bind 127.0.0.1`，打开 <http://127.0.0.1:8137/>。

站点部署在 GitHub Pages，来源为 `main` 分支根目录。网页采用相对路径，样式统一于 `pages.css`，不依赖第三方前端框架。

## 维护

- `build_pages.py` 用于重建四个 HTML 的导航和页面骨架。
- `build_content.py` 从原观点卡、场景资料、成员数据包和 `data.json` 的基础索引构建各页数据。`data.json` 是构建输入，浏览器不请求它。
- 如需更新原卡配图，先运行 `build_case_media.py`，再运行 `build_content.py`。这两步需要保留站点与任务材料的相对目录位置，并使用包含 Pillow、pypdf、python-docx 和 python-pptx 的 Python。
